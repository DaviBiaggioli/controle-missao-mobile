# Controle de Missão Espacial 🚀

Solução Integrada Backend + Mobile desenvolvida para a disciplina de Advanced Programming And Mobile Dev.

## 🛠️ Tecnologias Utilizadas
* **Backend:** Java, Spring Boot, Hibernate, Banco H2 (Modo File), REST API.
* **Mobile:** React Native, TypeScript, Expo, Axios, React Navigation.

## ⚙️ Arquitetura e Funcionalidades
* **Banco Normalizado (3 Tabelas):** `SistemaMonitorado`, `Sensor` e `RegistroOperacional`.
* **CRUD Completo:** Inserção via formulário e edição/exclusão via Modal Interativo.
* **Integração:** Comunicação via API REST (GET, POST, PUT, DELETE).
* **Interface:** Design limpo, focado na usabilidade, com alertas visuais dinâmicos.
